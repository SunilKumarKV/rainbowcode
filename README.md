# RainbowCode

RainbowCode is a global design-to-code platform where users visually create and customize logos, themes, components, pages, and design systems. Every change updates live preview and generates production-ready code. Developers can export or install assets through the RBC CLI.

## First Build Priority
1. Monorepo setup
2. Next.js web app
3. Tailwind design system
4. Dashboard layout
5. Editor layout: sidebar, canvas, properties panel, generated code panel
6. Theme token engine
7. Button builder prototype
8. Code preview/export
9. Docs structure
10. CLI package structure

## Tech Stack
- Next.js

- Tailwind CSS
- Radix UI
- Konva.js
- Zustand
- React Hook Form
- Zod
- PostgreSQL
- Prisma
- Auth.js
- Cloudflare R2
- Redis + BullMQ later
