# RainbowCode AI Rules

You are working on RainbowCode, a production-grade design-to-code platform.

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- React
- Component-based architecture

## Rules
- No dummy placeholder code.
- No breaking existing routes.
- Keep UI clean and responsive.
- Use reusable components.
- Add types properly.
- Follow existing folder structure.
- Do not install packages without asking.
- After changes, run:
  - pnpm typecheck
  - pnpm lint
  - pnpm build
